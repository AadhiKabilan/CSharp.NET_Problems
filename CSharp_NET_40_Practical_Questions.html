Assignment instructions

Implement each question as a small C# console application unless the question requests multiple projects. Use in-memory data and local files where specified. No external services are required.

For each assignment, submit source code and console evidence for valid, boundary and invalid inputs. Keep intentionally invalid compile-time examples commented out. Use the supplied sample values and add at least one additional test of your own.

Data handling and application input

Q01

Invoice value exchange

Boxing and unboxing

A billing component receives invoice values through object variables.

Your task
  1. Use invoice number 1001, total 2499.50m and paid status true as sample values.
  2. Store each value in an object variable and recover it using the correct original value type.
  3. Demonstrate what happens when the boxed invoice number is treated as a long instead of its original type; keep the application running.
  4. Produce a short console report showing original type, stored value and recovered type.
